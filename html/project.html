AI Smart Waste Segregation System

Automatic Waste Detection using Artificial Intelligence

About Project

This project uses Artificial Intelligence and image processing to identify waste such as plastic, paper, metal and organic materials. The system automatically classifies waste and sends it to the correct dustbin.

Working Process

🗑 Waste Object ⬇ 📷 Camera Captures Image ⬇ 🤖 AI Model Predicts ⬇ ⚙ ESP32 Receives Result ⬇ 🔄 Servo Rotates ⬇ ♻ Waste Goes to Correct Bin
